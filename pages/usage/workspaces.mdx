Workspaces are the top-level organizational unit in OvB. All sessions, cases, and settings belong to a workspace.

## Types of Workspaces

| Type | Description |
|---|---|
| **Personal** | Created automatically when a user signs up. Private to the user. |
| **Team** | Shared workspaces with multiple members. Requires admin permission to enable. |

Whether personal or team workspaces can be created is controlled by the admin.

## Roles

Workspace roles follow a strict hierarchy — each role gains everything the role below it can do.

| Role | Permissions |
|---|---|
| `owner` | Full control: manage members, settings, and sessions; delete the workspace |
| `admin` | Manage members and settings; cannot transfer ownership or delete the workspace |
| `member` | Write to [persistent storage](/usage/persistent-storage) (upload, delete, mkdir) plus everything below |
| `analyst` | Launch sessions, create and edit cases, manage case attachments and workspace file links plus everything below |
| `viewer` | Read-only: browse and download files, view cases, and post comments |

## Creating a Workspace

If workspace creation is enabled by the admin:

1. Go to **Workspaces** in the sidebar
2. Click **Create workspace**
3. Enter a name and confirm

The creator becomes the workspace owner.

## Managing Members

Workspace owners and admins can:

- Invite users by email or username
- Change a member's role
- Remove members

## Workspace Settings

Each workspace has independent settings that can override the global defaults:

| Setting | Description |
|---|---|
| Browser allowlist | Restrict which browsers/OS images members can use |
| Idle timeout | Override the default session idle timeout |
| Concurrent session limit | Maximum simultaneous open sessions per user |
| Max session duration | Override the hard cap on how long a single session can run (hours) |
| Network logging | Enable or disable traffic logging for this workspace |
| File protection | Enable or disable encrypted file downloads for this workspace |
| Persistent storage | Enable or disable S3-backed persistent downloads for this workspace |

Workspace-level settings take precedence over global defaults (SiteSettings) when set. See [Persistent Storage](/usage/persistent-storage) for details on the storage feature.

## Switching Workspaces

Use the workspace switcher in the sidebar to move between workspaces. Sessions and cases are scoped to the workspace they were created in.

## Deleting a Workspace

Only a workspace **owner** can delete a workspace. This also happens automatically when the last member leaves.

Deleting a workspace permanently removes the workspace, all memberships, sessions, cases, notes, and tags. If persistent storage was enabled, OvB **automatically** deletes the workspace's S3 access point and all stored files — the data is not recoverable. See [Deleting Workspace Data](/usage/persistent-storage#deleting-workspace-data) for details.
