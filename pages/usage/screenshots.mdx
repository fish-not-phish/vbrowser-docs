# Screenshots

Screenshots let you capture the current state of a browser session as a PNG image. The file is downloaded directly to your computer — it is not stored on the server or in S3.

## Taking a Screenshot

1. Open an active session in the session viewer
2. Click the **Screenshot** button in the toolbar
3. The PNG downloads immediately to your computer

The screenshot captures the full visible browser viewport at the moment you click.

## Limitations

| Constraint | Details |
|---|---|
| Format | PNG only |
| Scope | Captures the browser viewport — not the full page or off-screen content |
| Kali Linux | Captures the full desktop environment, not just the browser window |
| Storage | Downloads to your computer — nothing is stored server-side |
